React JS Techinal Test

Frontend Techinal Test menggunakan React JS dan Vite.

Cara menjalankan project:

A. Requirements
Untuk menjalankan project, komputer harus memiliki:
1. Node.js
2. npm

Untuk mengecek apakah komputer sudah memiliki requirements yang diperlukan, bisa dicek dengan:

node -v
npm -v


B. Install Dependencies
Jalankan,

npm install


C. Jalankan Project
Jalankan,

npm run dev
